# Frontend

Choose by the interface problem or interaction you want to improve.

<!-- skills:start -->

## Design and usability

- [ui-design](ui-design/SKILL.md) — Shape an interface around its content, tasks, and product identity.
- [responsive](responsive/SKILL.md) — Fix reflow and access across widths and enlargement.
- [accessibility](accessibility/SKILL.md) — Review or improve keyboard, focus, semantics, and perceivable states.
- [mobile-web](mobile-web/SKILL.md) — Fix touch, viewport, keyboard, and mobile browser behavior.
- [ui-stress](ui-stress/SKILL.md) — Exercise realistic content extremes and task states.
- [prototype](prototype/SKILL.md) — Compare UI directions or explore business rules in an isolated demo.
- [ui-library](ui-library/SKILL.md) — Choose components for a concrete capability gap.

## Build motion

- [animate](animate/SKILL.md) — Implement web transitions, gestures, and feedback.
- [animate-native](animate-native/SKILL.md) — Implement React Native or Expo motion and gestures.

## Understand and improve motion

- [animation-vocabulary](animation-vocabulary/SKILL.md) — Name an observed effect and distinguish similar motion.
- [animation-opportunities](animation-opportunities/SKILL.md) — Identify useful places to add motion.
- [animation-review](animation-review/SKILL.md) — Review a selected interaction or motion change.
- [animation-audit](animation-audit/SKILL.md) — Inventory motion across a project and prioritize improvements.
- [animation-debug](animation-debug/SKILL.md) — Diagnose jumping, flickering, delayed, or stuck motion.
- [animation-performance](animation-performance/SKILL.md) — Measure and improve frame pacing and responsiveness.
