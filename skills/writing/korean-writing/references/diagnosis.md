# Korean diagnosis by meaning

Read the matching case when a passage is hard to interpret. Korean examples
illustrate decisions; they are not phrase bans, frequency thresholds, or automatic
replacements. Compare surrounding context and preserve uncertainty, genre, and voice.

| Symptom and evidence | Possible revision | Retain or clarify when |
| --- | --- | --- |
| "서버가 응답하지 않았다. 이것을 다시 실행한다." does not identify what to repeat | Name the intended operation, such as "요청을 다시 보낸다", only when context establishes it | Several actions could be meant: resolve the meaning before editing |
| "고객의 요청의 처리의 지연" obscures which process is delayed | "고객 요청 처리가 늦어졌다" when it denotes that event | A possessive or technical term expresses an actual relationship that must remain |
| "권한 변경이 적용되어지게 된다" layers predicates without adding a condition | "권한 변경이 적용된다" if the same event and certainty are intended | "적용될 수 있다" expresses possibility; removing it would strengthen the claim |
| "팀이 배포했다. 따라서 오류가 줄었다." asserts an unsupported causal link | State the observed timing separately if that is all the evidence supports | A causal relation is supported or explicitly attributed to a source |
| "이 기능은 효율성을 높인다" leaves the benefit unspecified | Use a supplied concrete effect, such as "파일을 한 번에 올릴 수 있다" | No evidence establishes a more specific benefit: preserve attribution or flag the gap |
| "검토를 진행하고 있다" seems longer than necessary | "검토하고 있다" keeps the ongoing action | "검토했다" or "검토한다" would change time or aspect |

For a proposed edit, identify what the reader could misunderstand, then compare
who acts, what happens, when, under which condition, and with what certainty.
Keep a passage that already makes those relationships clear. Grammar or pattern
counts alone cannot establish poor writing, AI authorship, or semantic preservation.
