# Writing

Choose by the text you need to produce or revise. Each skill works alone and declares its own license.

<!-- skills:start -->

## Draft, revise, or summarize

- [write](write/SKILL.md) — Draft new reader-facing prose from a brief or evidence.
- [rewrite](rewrite/SKILL.md) — Edit or review existing prose while preserving meaning and voice.
- [summarize](summarize/SKILL.md) — Compress a specified source while preserving its essential facts.

## Write developer documentation

- [readme](readme/SKILL.md) — Create or review a package README for consumer setup and first use.
- [dev-docs](dev-docs/SKILL.md) — Create or review broader developer guides, references, and examples.

## Refine language

- [korean-writing](korean-writing/SKILL.md) — Create, edit, or review Korean expression and information flow.
- [english-writing](english-writing/SKILL.md) — Create, edit, or review English expression and register.

## Set conversational delivery

- [clear](clear/SKILL.md) — Answer with essential detail for readers with limited attention.
- [terse](terse/SKILL.md) — Use blunt, concise conversation when requested.
- [brief](brief/SKILL.md) — Present requested status and handover briefings.

<!-- skills:end -->

## Install

Run from the target project; replace `readme` with one or more names above:

```bash
npx @jinyongp/agentskills@latest add --agent codex --skill readme
```

See [installation requirements and alternatives](../../README.md#quick-start).

Language guidance can refine a drafting or editing task. Conversation styles retain
the full task scope and the deliverable's genre. Clients decide skill activation;
installing several skills does not guarantee automatic composition.
