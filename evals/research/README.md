## Input budget and verification

No inspection script is needed: source collection depends on the selected research
tools. Native pages have no universal measured ceiling. Use targeted sections and
counts/recovery queries for large exports. Format and catalog checks verify packaging;
source selection, synthesis quality, and causal skill benefit remain unmeasured.
